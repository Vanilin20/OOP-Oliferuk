## Мета
Закріпити навички використання перевантажених конструкторів для створення гнучких та зручних у використанні класів.

## Хід роботи
1. Створено консольний проєкт `IndependentWork4`.
2. У файлі `Program.cs` оголошено клас `Product` для системи інтернет-магазину з read-only властивостями: `Id`, `Name`, `Price`, `Category`, `StockCount`.
3. Реалізовано 3 перевантажені конструктори:
   - **Основний конструктор**: ініціалізує всі 5 полів.
   - **Скорочений конструктор**: приймає `id`, `name`, `price` та викликає основний через `: this(id, name, price, "Uncategorized", 0)`.
   - **Конструктор копіювання**: приймає інший об'єкт `Product` та викликає основний через `: this(...)`.
4. Перевизначено метод `ToString()` для форматованого виводу даних про товар.
5. У методі `Main` продемонстровано створення товарів за допомогою кожного з трьох конструкторів.

## Висновок
Під час виконання роботи було досліджено механізм перевантаження конструкторів в C#. Використання синтаксису `: this(...)` дозволяє уникнути дублювання коду ініціалізації полів, робить клас гнучкішим, а використання read-only властивостей гарантує цілісність даних об'єкта після його створення.
